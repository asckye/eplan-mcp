## Examples

```json
{"project":"Line1","page":"P","items":[{"kind":"text","position":[10,20],"contents":{"??_??":"Panel"},"height_mm":3},{"kind":"line","points":[[10,10],[30,10]]},{"kind":"rectangle","corners":[[5,5],[40,30]]}]}
```
## Workflow
Placement preflight and execution each allow 180 seconds, including preview preflight. Other reads keep their usual limits.
Omitting dry_run (or true) previews only: no approval, no project/file writes, execution=not_started. Call again with dry_run:false to execute; preview hint explains this step.
Full profile. Execution creates the complete batch atomically, reads every item back and supports one-step undo; outside scratch needs approval. Never repeat a committed or unknown call. A failed batch rolls back everything without an undo step.
## Fields
One Circuit, Overview or Graphics page, 1-50 items; coordinates in mm, bottom-left origin, y up, 0-10000. snap_to_grid defaults true; the preview reports requested and actual geometry plus full bounds. Text height is 0.5-100 mm, at most 500 characters across explicit languages. Never mix ??_?? with languages. Supply ??_?? or at least the project display language: other text is invisible (A54). Kinds: text, line, rectangle, polyline, arc, ellipse, path_text, image. Polyline points require at least two vertices and remain open. Arc uses center, positive radius_mm and start_angle/end_angle in degrees; equal angles modulo 360 create a Circle. Ellipse takes center, positive radius_x_mm/radius_y_mm and optional angle in degrees (default 0). Arc/ellipse guarded bounds use the largest radius. Path_text is native path function text for device function descriptions and reports; it takes position and contents; omit height_mm to use the EPLAN default (-16002 readback), or supply 0.5-100 mm. Image takes file (relative to imports, .png/.jpg/.jpeg/.bmp/.emf/.wmf) and corners (two opposite points). Absolute paths, traversal and links are rejected. Lines are graphics. No connection generation. concise/detailed budgets are 5k/20k, with complete impact lists.
## Errors
INVALID_ARGUMENT reports JSON Pointer violations for schema, languages or full-outline bounds. CAPABILITY_MISSING reports missing reliable page geometry or display language. Preflight failures and previews report execution=not_started; failed writes report rolled_back or unknown. Execution reports boundarySource=unverified and bounds=null: the result warning reports the page-size-minus-margin fallback and measured containment checks. Use reliable text measurements; plot-frame size and character-count estimates are not fallbacks.
Layout preflight refuses R1-R5/R8 with a rule and, when available, a suggested grid position. R6/R7/R9 are warnings unless layout.strict is enabled. Boundary fallback uses Page.Size minus layout.marginMm. Incomplete prediction is allowed: check insertion points, known outlines and routes before writing; measure symbols and property texts in the same call before commit and roll back violations. Results report both check stages and the fallback; refusals include measured geometry and nearest free positions in metadata.layoutViolations/layoutChecks. Connection geometry available only after commit uses existing undo compensation.
