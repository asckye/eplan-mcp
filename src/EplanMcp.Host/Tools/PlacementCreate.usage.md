## Workflow
Placement preflight and execution each allow 180 seconds, including preview preflight. Other reads keep their usual limits.
Omitting dry_run (or true) previews only: no approval, no project/file writes, execution=not_started. Call again with dry_run:false to execute; preview hint explains this step.
Full profile. Execution creates the complete batch atomically, reads every item back and supports one-step undo; outside scratch needs approval. Never repeat a committed or unknown call. A failed batch rolls back everything without an undo step.
## Fields
Block: a call contains only one `{kind:"block",members:[locator,locator],name:"drawing-block"}` item. Obtain 2-1000 distinct members from eplan_page_get include_drawings on the same page; name is optional. Results summarize count/name; reacquire locators after commit because members change identity and use relative coordinates. Native execution is awaiting Large verification.
One Circuit, Overview or Graphics page, 1-50 items; coordinates in mm, bottom-left origin, y up, 0-10000. snap_to_grid defaults true; the preview reports requested and actual geometry plus full bounds. Text height is 0.5-100 mm, at most 500 characters per explicit language, with no combined limit. Never mix ??_?? with languages. Supply ??_?? or at least the project display language: other text is invisible (A54); layout_guard:warn permits it with a warning. Kinds: text, line, rectangle, polyline, arc, ellipse, path_text, image. Polyline points require at least two vertices and default to open; closed:true retains the vertices and closes the polyline. Arc uses center, positive radius_mm and start_angle/end_angle in degrees; equal angles modulo 360 create a Circle; identical endpoints preserve both angles, while full-turn spans use SetCircle. Ellipse takes center, positive radius_x_mm/radius_y_mm and optional angle in degrees (default 0). Arc/ellipse guarded bounds use the largest radius. Path_text is native path function text for device function descriptions and reports; it takes position and contents; omit height_mm to use the EPLAN default (-16002 readback), or supply 0.5-100 mm. Image takes file (relative to imports, .png/.jpg/.jpeg/.bmp/.emf/.wmf) and corners (two opposite points). Absolute paths, traversal and links are rejected. Lines are graphics. No connection generation. concise/detailed budgets are 5k/20k, with complete impact lists.
## Errors
INVALID_ARGUMENT reports JSON Pointer violations for schema, languages or full-outline bounds. CAPABILITY_MISSING reports missing reliable page geometry; unreadable display language is a warning. Preflight failures and previews report execution=not_started; failed writes report rolled_back or unknown. Execution reports boundarySource=unverified and bounds=null: the result warning reports the page-size-minus-margin fallback and measured containment checks. Use reliable text measurements; plot-frame size and character-count estimates are not fallbacks.
Layout preflight refuses R1-R5/R8 with a rule and, when available, a suggested grid position. R6/R7/R9 are warnings unless layout.strict is enabled. Boundary fallback uses Page.Size minus layout.marginMm. Incomplete prediction is allowed: check insertion points, known outlines and routes before writing; measure symbols and property texts in the same call before commit and roll back violations. Results report both check stages and the fallback; refusals include measured geometry and nearest free positions in metadata.layoutViolations/layoutChecks. Connection geometry available only after commit uses existing undo compensation.

All primitives accept layer ID and pen:{color,width_mm,style,pattern_length,line_end}; each pen field is optional; color/width_mm/style/pattern_length accept -16002 for the EPLAN default, while line_end accepts 0..2. Polyline accepts closed; rectangle/text/path_text accept angle in degrees (-16002 uses the layer unchanged); other angles are compared modulo 360; text accepts alignment (exact EPLAN name, e.g. MiddleLeft or FromLayer). Styles are read back; measured rotated bounds use the existing layout checks.

Use layout_guard:"warn" to reproduce existing drawings; keep the default "refuse" for free drawing. Pre-write layout findings become warning text, bounded by LayoutGuard.Summary; R1 outside Page.Size still refuses. Post-write checks and ADR-0046 are unchanged.

Block members with stale locators return PLAN_STALE; another page, duplicate or block-owned members (non-null parent) return INVALID_ARGUMENT; grouped:true alone is allowed.
