## Errors
POLICY_DENIED: off/unknown/excluded/outside scratch; approval cannot bypass. INVALID_ARGUMENT: shapes/types/cursors; PLAN_STALE: rediscover/reacquire/replan. Approval denied/expired/unavailable or AUDIT_UNAVAILABLE: no execution. OUTCOME_UNKNOWN (timeout/modal): project/instance writes suspended; never repeat; engineer inspects EPLAN/confirms recovery via approval.
