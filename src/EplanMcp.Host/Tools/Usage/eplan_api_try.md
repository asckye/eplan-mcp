## Workflow
Get exact groups/templates from eplan_api_search/eplan_api_get, fresh locators from eplan_object_find. Replace whole locator/handle/path placeholders from declared sources. INVALID_ARGUMENT carries the closest template, including pre-dispatch errors. Requires full + config.json apiTry:on; the generated catalog defines signatures/kinds/receivers. Exact parameter-name sets select one overload; ambiguity fails. Get*/Is*/Has*/Can*/Find* without side-effect parameters are reads; other methods write. Native target parameters become argument_target. Remove dry_run only for independent per-call approval: read/write unverified API <group>, with = <value> for setters. Unimplemented groups: not_dispatchable_yet; unsupported setters: validation error.
Settings use a scratch Project target; Project.Settings returns PROJECT. Enumerate USER/STATION/PROJECT with SettingNode.GetListOfNodes. Supply node, offset (0..1000000), limit (1..200); omit native ref containers/bAbsolutPath. GetListOfSettings lists leaves; GetListOfAllSettings recurses. value is JSON text {items,total,nextOffset}; continue at nextOffset. Follow enumerated children/leaves only; value reads take node, relative strSettingPath and published idx/nIdx (0..1000000). ProjectSettings/ProjectSettingNode require PROJECT; Base.Settings requires USER/STATION. Scheme lists are children of enumerated SCHEMES nodes; SchemeSetting reads metadata/current-scheme values without switching schemes or writing LastUsed. Multilingual text retains language tags. Planning/execution re-enumerate every segment/leaf. COMPANY/INSTALL, direct ISettings groups, setters, Set*/Save*/Load*/Import*/Export*/Reset*, other settings mutations and scheme selection are unavailable. Reads require approval/snapshots, no undo step; snapshots omit USER/STATION settings stores. ref containers stay inside this adapter.
## Fields

Static calls omit target. Entries take a parent locator + case-sensitive generated via path (max two properties), e.g. Project + via:"Settings" for ProjectSettings.GetBoolSetting. LayerTable.Layer requires nonempty string via_key; other paths forbid it. Use eplan_project_list then eplan_object_find for Project locators. Settings/schemes stay read-only; static file/network/licensing/application/master-data calls stay excluded.

File directions: input/import/source read Host imports; output/export/target/destination write exports. Otherwise catalog docs then Import/Read/Load or Export/Write/Save verbs determine direction; ambiguous paths/directories stay excluded. Inputs: relative paths <=260 characters, <=128 MiB; outputs: names <=100 characters in fresh server-assigned exports/api-try-<id>. No rooted/UNC paths, traversal, reserved names, trailing dots/spaces or reparse points. Input size/SHA-256 bind approval and are rechecked before execution. files lists exports-relative path/bytes/sha256, <=100 files, <=128 MiB each, checked before transaction commit. External files persist after project undo; failure/unknown may leave partial files. Printing/sending/master-data/settings writes/implicit destinations stay excluded.
group is an exact O: ID; project is explicit; parameters preserves raw JSON <=2048 characters. target has a discovery digest. Omit value for property reads; setters accept bool/Int32/finite double/string/exact case-sensitive enum names. Methods also accept Int64, finite PointD {"x":number,"y":number} and fresh supported same-project locators (derived Function types included). Only generated parameter kinds are accepted; null/arbitrary objects/coercion fail. All trials are unverified. value is invariant scalar text, a discovery locator with identity digest, null for void, or settings page JSON. before/after summarize standard-v1 page snapshots, counts and action-run design-file size/time fingerprints. changes starts with property:<group> even if equal, then changed snapshot/file keys, <=20 entries; property values are JSON-encoded scalar text. totalChanges counts observations; truncated marks omitted keys. Snapshots omit unplaced objects/3D connections; equality proves no absence of side effects. Recovered calls infer no readback. Reads create no undo step. Property writes read back before commit; method writes observe snapshots without re-invoking. Writes use one SafetyPoint/undo step; exceptions/mismatches roll back. Live undo verification is pending; committed cleanup warnings appear in hint.
## Errors
POLICY_DENIED: off/unknown/excluded/outside scratch; approval cannot bypass. INVALID_ARGUMENT: use exact shapes/fresh locators. PLAN_STALE: rediscover/replan. Approval denial/expiry/no channel and AUDIT_UNAVAILABLE execute nothing. OUTCOME_UNKNOWN (timeout/modal) suspends project/instance writes: never repeat; ask the engineer to inspect EPLAN and confirm recovery via approval.
