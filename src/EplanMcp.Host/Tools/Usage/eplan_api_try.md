```json
{"group":"O:Eplan.EplApi.DataModel.Page.Name","project":"Scratch","parameters":{"target":{"project":"Scratch","page":"=A/1","type":1,"oid":1,"digest":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"}},"dry_run":true}
```
Set a scalar property by adding value to the same group (dry run first):
```json
{"group":"O:Eplan.EplApi.DataModel.Page.GridSize","project":"Scratch","parameters":{"target":{"project":"Scratch","page":"=A/1","type":1,"oid":1,"digest":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"},"value":2.5},"dry_run":true}
```

```json
{"group":"O:Eplan.EplApi.DataModel.Page.GetWriteProtectionFlagSet","project":"Scratch","parameters":{"target":{"project":"Scratch","page":"=A/1","type":1,"oid":1,"digest":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"},"nKind":"Manual"},"dry_run":true}
```

## Workflow
Use eplan_api_get try_template instead of guessing parameters. Replace complete locator/handle/path placeholders with fresh values from the declared source. INVALID_ARGUMENT includes the nearest signature template, including errors detected before dispatch. The runtime generated catalog determines the supported signatures.
Discover the exact group with eplan_api_search/eplan_api_get, then get a fresh locator from eplan_object_find. Full profile and config.json apiTry:on are required. The generated dispatch catalog is authoritative for supported groups, parameter kinds and receiver sources. Methods select one signature by the exact parameter-name set; ambiguous calls fail. Get*/Is*/Has*/Can*/Find* methods are reads; other methods are writes. A method parameter named target is exposed as argument_target; target always identifies the receiver. Remove dry_run only when ready for independent per-call approval: read unverified API <group>, or write unverified API <group> (property setters also show = <value>). Other registered groups return not_dispatchable_yet; unsupported setters fail validation.
## Fields

Public static calls omit target. Entry calls use a parent target locator and a case-sensitive generated via path of at most two properties, e.g. Project + via:"Settings" for ProjectSettings.GetBoolSetting. LayerTable.Layer requires a nonempty string via_key; other paths reject it. Get Project locators with eplan_object_find after eplan_project_list. Settings/schemes are read-only; static file/network/licensing/application/master-data calls remain excluded.

File parameters have generated input/output directions: input/import/source names read from the Host data folder's imports; output/export/target/destination names write to exports. Otherwise catalog documentation and Import/Read/Load or Export/Write/Save method verbs supply direction; ambiguous paths and directory parameters stay excluded. Inputs accept relative paths up to 260 characters and 128 MiB; outputs accept file names up to 100 characters in a fresh server-assigned exports/api-try-<id> folder. No rooted/UNC paths, traversal, reserved names, trailing dots/spaces or reparse points. Input sizes and SHA-256 bind approval and are rechecked before execution. files lists every output's exports-relative path, bytes and sha256 (at most 100 entries, 128 MiB per file), checked before committing the project transaction. External files persist after project undo; failures or unknown outcomes may leave partial files. Printing, sending, master data, settings and implicit destinations remain excluded.
group is an exact O: overload group, project is explicit, parameters retains raw JSON (maximum 2048 characters); target is a digest-checked discovery locator. Omit value to read; supply a bool, Int32 integer, finite double, string, or exact case-sensitive enum name to write a generated public setter. Method parameters also accept Int64, PointD as {"x":number,"y":number} with finite coordinates, and fresh locators for supported object types in the same project; enum values use exact catalog member names. Only parameter kinds emitted by the generated dispatch catalog are accepted; nulls, arbitrary objects and coercion are rejected. All trials are unverified. value is property readback or a method result: invariant scalar text, a discovery locator with the same identity digest, or null for void. before/after summarize standard-v1 page snapshots, object counts and action-run design-file size/time fingerprints. changes lists the property:<group> observation first, even when equal, plus changed snapshot/file keys, up to 20 entries; property before/after are JSON-encoded scalar text. totalChanges counts all observation entries; truncated signals omitted keys. Snapshots omit unplaced objects and 3D connections; equal observations are not proof of no side effects. Recovered calls have no inferred value or readback. Reads create no undo step. Property writes read back before commit; method writes record snapshots without invoking the method again. Each write uses one SafetyPoint/undo step; exceptions or property mismatches roll back. Live undo verification is pending; committed cleanup warnings appear in hint.
## Errors
POLICY_DENIED: disabled, unknown/excluded group or project outside scratch; approval cannot bypass it. INVALID_ARGUMENT: use the exact published shape and fresh locator. PLAN_STALE: refresh discovery and plan. Approval denial, expiry or unavailable channels execute nothing. AUDIT_UNAVAILABLE refuses execution. OUTCOME_UNKNOWN after timeout/modal blocking suspends project and instance writes: do not repeat; ask the engineer to inspect EPLAN and confirm recovery through the approval window.
