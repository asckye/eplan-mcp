## Workflow
Discover the exact group with eplan_api_search/eplan_api_get, then get a fresh locator from eplan_object_find. Full profile and config.json apiTry:on are required. The generated table contains 62 read groups and 41 write groups, covering Page, Function, Connection, Terminal, PLCTerminal, TerminalStrip, PLC, Cable, BlackBox, PlaceHolder, InterruptionPoint, PotentialDefinition, LocationBox and MacroBox locators. Function properties accept derived function locators too. Function.IsDeviceLocked(bWithCDPs: boolean) remains read-only. Remove dry_run only when ready for independent per-call approval: read unverified API <group>, or write unverified API <group> = <value>. Other registered groups return not_dispatchable_yet; unsupported setters fail validation.
## Fields
group is an exact O: overload group, project is explicit, parameters retains raw JSON (maximum 2048 characters); target is a digest-checked discovery locator. Omit value to read; supply a bool, Int32 integer, finite double, string, or exact case-sensitive enum name to write a generated public setter. Arrays, nulls, arbitrary objects and coercion are rejected. All trials are unverified. value is the scalar readback. before/after summarize standard-v1 page snapshots, object counts and action-run design-file size/time fingerprints. changes lists the property:<group> observation first, even when equal, plus changed snapshot/file keys, up to 20 entries; property before/after are JSON-encoded scalar text. totalChanges counts all observation entries; truncated signals omitted keys. Snapshots omit unplaced objects and 3D connections; equal observations are not proof of no side effects. Recovered calls have no inferred value or readback. Reads create no undo step. Writes read back before committing one SafetyPoint/undo step; exceptions or mismatches roll back. Live undo verification is pending; committed cleanup warnings appear in hint.
## Errors
POLICY_DENIED: disabled, unknown/excluded group or project outside scratch; approval cannot bypass it. INVALID_ARGUMENT: use the exact published shape and fresh locator. PLAN_STALE: refresh discovery and plan. Approval denial, expiry or unavailable channels execute nothing. AUDIT_UNAVAILABLE refuses execution. OUTCOME_UNKNOWN after timeout/modal blocking suspends project and instance writes: do not repeat; ask the engineer to inspect EPLAN and confirm recovery through the approval window.
