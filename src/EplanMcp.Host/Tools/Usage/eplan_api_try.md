## Errors

NameService:explicit Page/valid placed object; Reports.Update:valid page-bound report. UndockText:check read-only/write protection before transaction. Approval denied/expired/unavailable or AUDIT_UNAVAILABLE:no call. OUTCOME_UNKNOWN (timeout/modal):suspend project/instance writes; never repeat; engineer inspects EPLAN/approves recovery.
