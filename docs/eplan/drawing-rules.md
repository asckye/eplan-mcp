# EPLAN 作图通用规则（EES IEC 机械原理图）

| 项 | 内容 |
|---|---|
| 适用 | 用 EES 基本项目（`EES_Machine_Schematic_2026.zw9`，图框 `[EES]_FN1_001`，A3）画的 IEC 机械电气原理图 |
| 来源 | EES 图框的放置参考层；官方案例 EES_stacking_iec、EES_s7_1500 的页面和数据（2026-11-08 读取）；EPLAN 帮助；[api-notes](api-notes.md) 的实测 |
| 怎么用 | **每次画图前通读一遍，再读项目所属公司的作图配置（第 10 节）。** 这里是不分公司的通用规则；页号、器件标识格式、端子型号、接线点命名、导线截面等取值由公司配置给出，没有公司配置时按官方 EES 样例。画的时候逐节照做，画完按第 9 节逐项核对。规则和实测冲突时以实测为准，并回来改这份文档 |

## 1. 作图顺序（工程师的顺序，不能打乱）

1. **项目和结构**：从基本项目新建。结构标识：功能 `=GAA`（进线）、`=GAB`（DC 24V）、`=GAC`（AC 控制电压）、各设备功能（`=MA1`、`=EB1` …）、`=K1`（PLC）、`=KF`（急停）、`=PHA`（操作）；位置 `+UC1`（控制柜）、`+M`（机器现场）。
2. **页**：页号规则按公司配置（EES 默认每个功能从 1 开始；器件标识要带页号时，页号全项目连续）。每个设备功能分"功率"页和"传感器/信号"页；`=GAB` 有电源页和电位分配页（可按用途分几页）；PLC 每张卡一页总览 `&EFA1`、一页机架 `&EFS`；最后是报表页。
3. **部件**：先在部件库查到每个器件的部件号，器件一律按部件放置（`eplan_device_place part`、`eplan_macro_insert`），只有部件库里确实没有才用符号，并在交付说明里列出。
4. **电源**：进线 → 控制电压 → **电位分配页**（分配端子，见第 4 节）。
5. **PLC：先总览，再调用**（第 6 节）。总览卡要先做完：部件、占位符值集、编址，然后才画机架和其他页面。
6. **功能页**：一列一个回路，从上到下按第 2 节的行放；PLC 点在本页调用（不在 PLC 页上另画）。
7. **路径功能文本**：每列底部写这一列的用途（第 5 节）。
8. **连接**：生成连接（`eplan_connection_generate rebuild:true`），导线数据（颜色、截面）由连接定义点和电位定义给出。
9. **核对 PLC 地址**：编址在第 5 步总览做完时就做；这里合并挂错的点后，看每个点都有地址，缺了再编一次。符号地址不手写（第 5 节）。
10. **报表**：目录、端子排总览、端子图、电缆图表、部件汇总、部件列表、PLC 图表（`eplan_report_create`，表格用项目里的 `[EES]_F*`）。
11. **检查**：`eplan_check_run`；导出图片，和官方页对照第 9 节。

## 2. 页面版式（A3，`[EES]_FN1_001`）

**列**：10 列，每列 40 mm，列中心 x = 32 + 40k（k = 0…9，即 32、72、112 … 392）。一个回路、一个 PLC 点占一列，放在列中心；同一行并排的 PLC 盒（40 mm 宽）每个占一列。

**行**：图框自带放置参考层（编辑时显示的浅色元素，不打印），每类元件有固定的 y（mm）：

| y | 放什么 | 官方用法举例 |
|---|---|---|
| 284 / 280 / 276 / 272 / 268 | 母线 L1 / L2 / L3 / N / PE | 只画到本页用到的列（官方 x 44→96），左端流入、右端流出 |
| 248 | 保护装置 | 电机保护开关、断路器 |
| 240 | PLC/设备盒，连接点朝下 | **DQ 点**（变体 2，引脚朝下，第 6 节） |
| 212 | 触点、传感器 | 接触器主触点、辅助触点、按钮 |
| 184 | 设备盒，连接点上/下 | 黑盒（传感器、加热器）的中心 |
| 172 / 164 | 电缆 / 屏蔽 | 现场电缆的上段 |
| 120 | 端子 | 端子；端子排定义放 x=16 同一行，带说明（`-XD1 = 电机`） |
| 108 | 结构盒 | `+M` 位置框的上沿，框住现场设备和现场一侧的电缆 |
| 96 / 88 | 电缆、线圈 / 屏蔽 | 现场电缆定义线；接触器、继电器线圈 |
| 84 | GND、端子 | 0V 分配端子、GND 中断点 |
| 72 | PLC/设备盒，连接点朝上 | **DI 点**（变体 0，引脚朝上，第 6 节） |
| 68 | 触点映像 | 线圈下方，EPLAN 自动显示 |
| 64 | 电机 | 电机（在 `+M` 框内） |
| 24 | 底部文字，居中 | **路径功能文本** |

例外只在行被占用时才用，并保持同类元件在同一行。传感器页的供电端子可以放在上方（官方 y=256）。

## 3. 各类回路的画法（官方页面为准）

- **进线页**（官方 EES_stacking_iec、EES_s7_1500 的 =GAA/1）：进线端子 `-XD1`（1、2、3、N、PE）在端子行（120），主开关在保护器件行（248）**倒着画**：1/3/5 朝下接端子，2/4/6 朝上直接进母线（L1 284、L2 280、L3 276 拐角向右）；N、PE 从端子直接上到 272、268 再向右；右端是流出的中断点。电流从下往上再向右，不绕回。部件宏只有正向变体时，用符号库的倒置变体（如 `QL3` 变体 6，上下翻转、1/3/5 仍从左到右）再挂部件；不要用整体旋转的变体 2（L1 会到最右边，和端子交叉）。
- **电机（功率页）**：母线 → 电机保护开关（248，带部件和整定值）→ 接触器主触点（212）→ 端子 `-XD1`（120）→ 动力电缆 `-WD1`（96，部件、长度、芯线号）→ 电机（64）在 `+M` 框内。PE 走端子 PE 和电缆 GNYE 芯。DQ 点在上方 240，经接触器线圈（96）回 0V；线圈下面是触点映像。保护开关的辅助触点接 DI 点（72）。
- **端子部件**：控制线、动力线、PE 分别按导线截面选端子部件，型号按公司配置；导线截面超过端子容量时换大一号（如 16 mm² 用 ST 10 / ST 10-PE）。按部件放置，用部件模板自带的符号，除非公司配置指定了画法。
- **检测（暂用符号）**：传感器还没选型时用 `SSNE`（接近开关常开）放在 `+M` 框里；+24V 从一个分配出线点进本页下方横线，分到各 + 端子，向上经电缆到开关，信号经同一根电缆回到信号端子和 DI 点；电缆型号写"待定"。选定部件后换成部件（三线制加 0V）。
- **传感器（传感器页）**：24V 中断点 → 端子 `-XG1`（上 256 或 120）→ 信号电缆 `-WG1` → 传感器（黑盒 184 附近，带部件图片）→ 电缆 → 端子 → DI 点（72）。
- **阀、加热器**：同上，执行器在 `+M` 框内，经电缆和端子。
- **电位分配页**：分配端子用多接线点端子（如 QUATTRO），相邻端子靠鞍形跳线连通（同一行放置时跳线点相对，生成连接后自动连通）。照官方 EES 的 =GAB 页：每排端子 1 用一进三出的 `X4_B_1`（进线点接电源），其余端子用四个接线点在同一侧、全部出线的 `X4_B_2`；没用到的接线点不画线。端子型号和接线点命名按公司配置。24V 排在上（264，变体 0：出线点朝下，端子 1 的进线点朝上），0V 排在下（84，变体 6：出线点朝上，端子 1 的进线点朝下），0V 排右移 16 mm，避免引脚上下对齐。电源页的输出接到端子 1 的进线点；分支中断点从出线点引出（24V 线朝上、0V 线朝下），都是流出。
- **HMI 页**：照官方 EES 的 =PHA 页，单独一页把部件宏的正视图（如 MTP 系列宏的多线变体 3，约 1:1）放在上部；X80 的 L+、M 向下引出再向左接到流入的中断点（左边 x = 44，线间距 4 mm），FE 同样接 PE。宏里嵌套的子设备（如 `-K1-K1:FE`）插入后改成同一个标识。这一页不写路径功能文字：它会成为该列 PLC 连接点的功能文字，竖着压在线上（官方 =PHA 页也没有），面板型号写在页标题里。
- **急停**：急停按钮在 `+M` 或柜门结构盒内，经电缆接到安全输入；双通道。

## 4. 命名

- **器件标识格式按公司配置**，例如"页号 + 字母码 + 序号"（第 8 页的接触器 `-8QA1`），端子排、电缆、PLC 卡通常不带页号；宏插入的器件插入后改名成同样的格式。没有公司配置时用 EPLAN 的默认编号。
- **设备字母码（IEC 81346-2）**：`SJ` 急停（官方 EES 的 `-SJC1`）、`QA` 接触器、`FC` 保护开关/断路器、`KF` 继电器、`MA` 电机、`SF` 按钮/传感器、`PF` 指示灯、`PH` HMI/显示屏（官方 EES 的 `-PHA1`）、`TA` 变频器、`EB` 加热器、`MB` 电磁阀、`KE` PLC 卡、`XD` 动力/电源端子、`XG` 信号端子、`WD` 动力电缆、`WG` 信号电缆。
- **结构**：`=功能+位置-设备`；现场设备在 `+M`，柜内在 `+UC1`。
- **中断点**：
  - 名字按**提供这个电位的分配接线点**命名，看名字就知道从哪里来，不用 `24V`、`0V` 这种电位名；电源页送到分配页的那一对也按落点命名。具体格式按公司配置；官方格式 `24V21.2` = 24V、端子排 XD2 的端子 1、第 2 层。
  - 结构化项目里 `+` 不能放在端子排名里，用一个排一个极性（如 `XD1` 24V、`XD2` 0V）；同一个用电处的正负极用同一个接线点编号。
  - EES 项目里**中断点不带结构、全项目通用**：`=GAC-L1` 会存成 `-L1` 并和主母线 L1 配对（A122）。名字必须在不带结构时也唯一。
  - 中断点**两两配对**：一个接线点只给一个用电处；一个电位要给多处，就用多个接线点（QUATTRO 每个端子三个出线点，端子之间跳线），或者在第一个用电处再引出去。
  - 母线只用 `L1` `L2` `L3` `N` `PE`。
  - **方向**：始终给 `symbol_variant`。BP 4–7 箭头尖接线 = 流入（4 线在右、5 线在上、6 线在左、7 线在下）；BP 0–3 箭尾接线 = 流出（0 线在左、1 线在下、2 线在右、3 线在上）。用电页上所有电位（包括 0V、N）都是流入，分配页/电源页是流出；母线左端流入、右端流出。竖线上的标签竖排（`property_arrangement` `下方,90°` 或 `上方,90°`）。

## 5. 数据关联（必须建立，画完逐项核对）

| 数据 | 怎么来 | 工具 | 核对 |
|---|---|---|---|
| 器件 ↔ 部件 | 按部件放置；部件带功能模板、技术数据、触点映像 | `eplan_device_place part`、`eplan_macro_insert`、`eplan_device_update part` | `eplan_device_get` 的 `parts`；部件汇总里没有空行 |
| PLC 卡 ↔ 总览 ↔ 机架图片 ↔ 功能页的点 | 同一个设备：先总览建卡，再调用（第 6 节） | `eplan_macro_insert`（Overview）、`eplan_device_update`（改名并入）、`eplan_device_place plc_connection_point` | 机架图片上方有回到 `&EFA1` 的交叉引用；点上有卡的交叉引用 |
| PLC 点的地址 | 编址，不手写；**每次执行都要工程师审批（scratch 也要）**，先说好再发起 | `eplan_plc_readdress` | `eplan_plc_get` 的 `address`（如 `I2.0`、`Q1.0`）；点上显示地址 |
| PLC 点的符号地址 | **不手写，EPLAN 自动算出**（实测：不传时读到 `MA2+UC1-QA1_14`、`QM+UC1-KF1_A1`），值是"连线最终到达的设备 + 接点"，会穿过端子 | 不传 `plc_symbolic_address` | `eplan_plc_get` 的 `symbolicAddress` 指向最终设备；通讯点（CM PtP）没有符号地址属正常 |
| PLC 点的功能文字（注释） | 放点时写，中英文；路径功能文本仍要画（报表用） | `eplan_device_place` 的 `plc_text` | 点框里显示注释，界面和导出都有 |
| 路径功能文本 → 器件功能文字 → 报表 | 每列 y=24、列中心一条路径功能文本（不是普通文字） | `eplan_placement_create` `kind:"path_text"` | 部件表、端子图里有功能文字 |
| 端子 ↔ 端子排定义 ↔ 端子图 | 端子排定义带说明；端子按部件 | `eplan_device_place terminal_strip … part`（首个端子带 `terminal_strip_text`） | 端子图里每个端子有内外两侧目标和电缆 |
| 端子 ↔ 电缆芯线 ↔ 现场设备 | 现场接线一律经过电缆，电缆标识取 `+M`（`=MA1+M-WD1`）；芯线按导线对应：导线 locator 用 `eplan_connection_list response_format:"detailed"`（带两端设备和接点）找；端子接点 1 在上、2 在下 | `eplan_connection_create` 的 `cable_definition`；部件用 `eplan_device_update part` | 电缆图表有芯线和两端目标；端子图有电缆名 |
| 导线 ↔ 颜色、截面 | 电位定义（每个电位一个，带颜色）+ 连接定义点（截面、颜色）；定义点单独调用，不能和 `generate:false` 一起 | `eplan_connection_create` 的 `potential_definition`、`definition_point` | 导线上显示颜色、截面（如 `BK 1,5`、`DBU 0,75`）；截面按公司配置 |
| 线圈 ↔ 触点 | 同一器件的主、辅功能 | 按部件放置后用 `join_device` 放其余触点 | 触点上有回到线圈的交叉引用；线圈下有触点映像 |
| 中断点 ↔ 对端 | 同名两两配对 | `eplan_connection_create` 的 `interruption_point` | 每个中断点都有对端交叉引用（脚本统计同名数为偶数） |
| 现场设备 ↔ `+M` | 器件直接用 `=功能+M-…` 标识放置，再画位置框；画完检查标识，叠成 `+M.M` 的改回 `+M`（实测会出现） | `eplan_device_place location_box`、`eplan_device_update new_tag` | 设备标识是 `=功能+M-…` |

## 6. PLC

1. **先画总览**：每张卡一页 `&EFA1`，按**宏路径**插入 Overview 表示（变体 0），主设备改名为卡的标识。**插入时就选占位符值集**：Overview 变体 0 带一个没有名字的占位符对象，先用 `eplan_macro_get`（`representation:"Overview"`）看值集，插入时传 `values: {"": "<值集>"}`。I/O 卡和 CM 的变量是 `Baseunit`，值集把 BaseUnit 挂到卡上（电位组的第一张卡选浅色 `6ES7193-6BP00-0BA0 (BU15-P16+A0+2B)`，其余选深色 `6ES7193-6BP00-0DA0 (BU15-P16+A0+2D)`）；CPU 的变量是 `Artikelnummer`，选 `BA 2XRJ45 (6ES7193-6AR00-0AA0)`，总线适配器挂到子设备上（子设备改名为 `-KEC1`）。卡本身的部件仍要单独挂（A123）。不要用 `eplan_macro_insert part=`（会挂到所有主功能，A122）。**总览做完马上编址**（`eplan_plc_readdress`，要工程师审批，先说好），再画机架和功能页：后面放的点并入已编址的通道，一放下就显示地址。
2. **再调用机架图片**：机架页按卡顺序紧挨着插入多线图片，改名并入卡。ET 200SP 图片变体：DI/DQ 浅色 5、深色 6（带 AUX 端子 7/8）；F-DI 6；CPU 1；CM PtP 浅色 3、深色 4（均已实测）。图片的浅/深色要和 BaseUnit 一致。
3. **机架供电**：每个电位组第一张卡的 L+/M（CPU 为 1L+/1M）向下接分配中断点，流入（BP 5），标签竖排。
4. **功能页调用点**：点的符号按公司配置。官方 EES_stacking_iec 用带插头的 `PLC_CBOX_PLUG`（插在 240/72，引脚偏 4 mm）；不带插头的 `PLC_CBOX` 引脚就在插入点（DQ 插在 236、变体 2，DI 插在 76、变体 0）。一个点一列。**放点时传 `plc_address`**，值取总览上这个通道已编好的地址（`eplan_plc_get`）：后放的点是通道的另一个功能，自己不会带上总览的地址，不传的话点框里的地址行是空的（实测 MX_Dryer11）。**故障安全卡（F-DI 等）的点用安全符号 `PLC_S_CBOX`**（带黄色标记，几何和 `PLC_CBOX` 相同）。**放点时传 `plc_text` 写上注释**（中英文，如 `zh_CN@手动;en_US@Manual mode;`）：只靠路径功能文本时，EPLAN 界面上的点框不一定显示出来（实测）。符号地址是否手写按公司配置，不写时 EPLAN 自动算（第 5 节）。点框里依次显示：功能文字、符号地址、地址、卡的交叉引用、通道。
5. 不用 `eplan_plc_generate` 给已经画了图片的卡补总览（会清掉已有表示，A122）。
6. **放完所有点后核对名字**：每个点都应是 `=K1+UC1-KE…:<号>`。实测有一个点放置后变成了 `=QM+UC1-KE5:3`（归到了页的结构下），它不会并入总览上的点，编址时还会被当成另一块卡（分到 Q4.0）。发现后用 `eplan_device_update` 把 `=QM+UC1-KE5` 改名为 `=K1+UC1-KE5`（PLC 点可以并入已有的卡）。总览做完就编址时，合并后点的地址保留（实测 MX_Dryer11–13 的 KE5:3 都是 Q0.2），不用再编址；只有先放点后编址时，点上才会存着按另一块卡分到的旧地址，合并后要重新编址。
7. **编址后看总览页**：每个点左边显示地址，用到的点右边显示回到功能页的引用和列说明；没有显示就是还没编址或点没并入卡。

## 7. 已知的坑（实测）

- 中断点不带结构、全项目配对（A122）。
- 自动连线不看电位：上下对齐的两个空引脚会被连起来（24V 端子和 0V 端子对齐时短路）。分配端子两排要错开，或空引脚不要对齐。
- 一页可以放多个同标识的位置框（已修复，只有两角完全相同才算重复）。
- `eplan_placement_update` 在引脚很多的页上移动文字会被拒（已提修复），先排好再画，少靠事后移动。
- 接触器线圈的技术参数文字较长（约 55 mm，在线圈左侧），线圈左边至少空出一列；两个线圈不要相邻一列。
- **继电器转换触点**：11 是公共端，接电源；14（常开）接负载，12（常闭）不用时空着。电源从上面来时用 `W3` 变体 6（刀在上：第 2 个引脚朝上是 11，下面左 12、右 14），代号按引脚顺序给 `12`、`11`、`14`。变体 0 刀在下，会变成电源进 14、11 出去接负载。
- 同一页里，按部件放置的继电器会接走之前按 `join_device` 放好的接触器辅助触点（13/14 归到了继电器）。**接触器的辅助触点最后放**，放完用 `eplan_device_get` 核对归属。
- **电缆文字全部放在位置框里面**（官方样例的做法，否则压框）：型号文字不带规格（`ÖLFLEX CLASSIC FD 810`，规格在芯线那一行），位置框左边比电缆定义线起点再往左约 52 mm。左边放不下时整块右移（热风机页右移一列）。
- **T 节点用带方向的变体，不用变体 8 的圆点**（官方样例用 `TLRU/0`、`TLRO/0`）。EPLAN 帮助：不带编号的点是来源，目标 1 画直线，目标 2 画斜线。规则：来源 = 电从哪边来，目标 1 = 去用电器的支路，目标 2（斜线）= 干线继续。变体：横线向下（TLRU）或向上（TLRO）分支，左边来电 0、右边来电 1；竖线向右（TOUR）或向左（TOUL）分支，上边来电 2、下边来电 3。`eplan_connection_create` 的 `t_node` 用 `variant` 指定。
- 交叉引用在对端页画出来之前是空的（中断点只显示 `/`）。**EPLAN 界面不会回头刷新先画的页**：整个项目画完后，先画那几页流出的中断点在界面上仍是空的（导出 PDF、图片时会重新计算，是对的）。画完后关闭再打开项目（`eplan_project_close` / `eplan_project_open`），界面才刷新（MX_Dryer19 实测）。
- 一次调用里同一根电缆只能画一条定义线。两根芯线分在器件上下两侧时，把回线绕回下方，让一条定义线横穿所有芯线（同官方电机页）。
- `eplan_object_find` 不按页过滤时会在 36 条左右截断且不给续读 cursor；查连接用 `eplan_connection_list`（`response_format:"detailed"`）。

## 9. 画完检查清单

1. 每个元件在第 2 节规定的行、列中心上；同类元件同一行。
2. 每列底部有路径功能文本，没有普通文字代替。
3. 每个器件都有部件（部件汇总里没有缺部件的行）；缺部件的已列在交付说明里。
4. 每个 PLC 点有地址；符号地址指向最终设备；点上显示列的说明和卡的交叉引用。
5. 每张 PLC 卡：总览页、机架图片、功能页的点是同一个设备；图片浅/深色和 BaseUnit 一致。
6. 现场设备都在 `+M` 框内，经端子和电缆接入；电缆图表有芯线和两端目标。
7. 导线有颜色和截面；电位定义齐全。
8. 中断点：名字按分配端子；全部成对；用电页流入、来源页流出；标签不压线。
9. 端子图每个端子有两侧目标；端子排定义有说明。
10. `eplan_check_run` 没有错误；导出图片和官方同类页对照过。
