## 背景、范围与风险

负责人目标是 4014 组全部可调用（scratch、逐次审批）。[缺口清单](../eplan/operation-gap-inventory.md)与 [TSV](../../catalog/operation-gaps.tsv)中本类首阻为 **35 组**；计数不等于该类全部重载，也不重复计其他块的交叉约束。

包括 `PathInfo` 路径属性、`PathMap.ReSubstitutePath`、`AssemblyResolver.SetBinPaths`、`ProjectManagement.LoadDirectory`、隐式来源的 `Translate.ImportProjectTexts` 及数据库/隐式目的地参数。B3 的 `Export3D.ProjectToStep` 等仅需 imports/exports 适配者不重复计数。

scratch 参数不能约束实际读写路径；任意路径可读取客户数据、覆盖工作站文件，经链接逃逸或经 UNC 发送凭据。读取路径字符串、解析路径与实际文件访问风险不同，不能仅凭名字断言已发生 I/O。程序集搜索路径还可能改变后续代码加载，影响整个进程。

## 提议的安全调用方式

1. 先提供无文件访问的路径解析/脱敏读取，并逐签名证明它是否触发 I/O。读取外部资源优先由人选择并复制到 imports，执行只用固定副本及哈希；输出先写新建 exports，再由人取走。可在既有根内完成的继续归 B3，不要求全局路径例外。
2. 确需原位置读取/写入时，提议由独立人工界面建立一次性授权：绑定规范化文件/目录身份、操作方向、精确条目清单、大小/哈希、目标 scratch 与过期时间；不是模型提交绝对路径后直接生效。写入先备份、拒绝链接与设备路径、执行前复核，输出清单核验后报告恢复限制。
3. 审批明示“访问 imports/exports 外资源”、目标与影响范围、是否覆盖、能否恢复；显示路径受 SEC-12/隐私规则约束，不把本机路径入库。目录枚举有界、拒绝隐式扩大目标。UNC/远端目的地另须 ADR-0044；配置/库选择/程序集搜索路径另须 ADR-0036/0038 等决定。

所有候选继续默认关闭，使用随产品审阅的精确编译分支；调用前独立窗口逐次审批，展示 unverified、签名、参数、来源及超出 scratch 的具体效果，绑定实例、输入摘要和前置状态；拒绝/取消/过期不执行。审计先行，不能由模型代答或修改策略；审批不免除同项目/路径/许可等独立前提。结果未知或恢复失败沿 ADR-0010 暂停相应目标和实例，不自动重发。

## 仍不能开放的部分

任意模型绝对路径、任意 UNC、链接逃逸和覆盖真实客户项目不开放。仅备份本地文件不能收回已经发往远端的数据；无法约束隐式目的地的调用继续不可执行。工具不能修改 Host 安全根目录来给自己授权。

## 备选方案与代价

维持固定根目录最简单；复制资源进 imports/exports 常可满足需求且不扩大权限；一次性人工原路径授权适用必须保留原位置的调用，但要付出竞态、备份和恢复复杂度；任意路径加一个总确认风险过大。

## 需要项目负责人决定

是否优先全部转为受控副本，仅少量签名支持人工原路径授权？允许哪些只读外部资源或备份可恢复的文件写入？程序集搜索路径等持久系统影响是否始终限制于隔离测试环境？

本 ADR 只提出该类别的审阅边界；请分别选择接受、修改或维持排除，并记录日期、明确范围和确认原话。其他九类不随之获准；需要逐组例外时另留批准记录。接受前不修改安全标准或运行时策略，不将不可执行项抵充 4014 完成数。

## 决定（2026-11-01）

项目负责人 2026-11-01 确认原话：“按你推荐的来，接受 ADR-0036 到 0045”。按本文“提议的安全调用方式”接受；“仍不能开放的部分”继续排除，也不抵充 4014 完成数。所有候选仍默认关闭，按随产品审阅的精确编译分支逐组开放；逐次审批、scratch 限定与实机验证要求不变。本决定只接受本类别的审阅边界，逐组例外仍须留下批准记录。

## 后续验证与依据

Small/Medium 覆盖路径规范化、重解析点、审批后替换、目录边界/文件 ID、备份失败和授权重放；Large 在 scratch 与非客户临时资源上核对真实 I/O、隐式目的地及失败后产物。

本次仅离线文档盘点，以上机制均为待验证提议，未运行 EPLAN，也不宣称备份、恢复或看门狗已实现。实现前把精确 API 行为的官方/获准 scratch 证据写入 [api-notes](../eplan/api-notes.md)，新增 Large 待验记入[台账](../process/large-pending.md)。缺失或不可读数据只给警告和证据缺口，不据此判违规；独立成立的写保护、审批、权限及恢复前提仍有效。
