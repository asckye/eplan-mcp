## 3. 不可调用的 1266 组：哪些还能做

分三档：**能做**（只要扩生成器或适配器，不改安全规则）、**要负责人决定**（需改安全分级或开 ADR）、**做不了**（API 本身决定的）。

| 原因 | 组数 | 档 | 判断 |
|---|---:|---|---|
| 声明类型拿不到句柄（`declaring_type_unreachable`） | 506 | 能做（部分） | 4 层内没有批准的返回链。逐类型找入口：`Base` 140、`DataModel` 113、`ApplicationFramework` 78（多为插件基础设施，见下）、主数据 60。估计能补一半左右 |
| 静态或非公开（`static_or_nonpublic`） | 162 | 能做（部分） | 132 组在 `DataModel`，多为静态工厂和工具方法；生成器支持静态调用形状后可补，非公开的不做 |
| 形状不支持或有歧义 | 98 | 要负责人决定 | 负责人 11-14 决定先放着；其中 `ISettings` 写入属于改设置 |
| 共享的交互状态（GED 交互） | 60 | 做不了 | 依赖用户正在进行的插入交互和光标，脚本中没有这个状态 |
| 主数据和部件库管理 | 89 | 要负责人决定 | ADR-0054 已允许读任意库、只写 scratch 下的文件副本；把这 89 组按同一规则开放需要负责人确认，系统库操作仍拒绝 |
| 外部路径参数 | 50 | 要负责人决定 | ADR-0042 外部路径授权：限定在 scratch 下的输入输出目录即可开放 |
| 抽象服务（`EServices` 校验基类） | 46 | 做不了 | 只能在插件里继承实现，不是可调用的 API |
| 临时对象创建（`CreateTransient`） | 43 | 能做 | 临时对象用于预览，不进项目；要给句柄加“临时”生命周期，读完即弃 |
| 禁用符号 | 38 | 做不了 | 目录规则禁止（筛选器、从主数据加载等会弹窗或绕过事务） |
| 返回值不支持 | 35 | 能做 | 3D 的向量、包围盒、平面集合等返回结构，补序列化即可 |
| 没有公开默认构造 | 34 | 能做（部分） | 枚举器类按集合返回已覆盖其内容；其余逐个看 |
| 参数不支持 | 27 | 能做 | 3D 坐标、Mate 参数等，补参数构造 |
| 设置与方案参数 | 26 | 要负责人决定 | 改设置；可按 action 普查的做法前后备份、恢复 |
| 枚举器类型 | 13 | 做不了（不需要） | 集合内容已经经集合返回读到 |
| 生命周期与创建 | 11 | 要负责人决定 | 锁定设备、初始化库等，影响会话 |
| 引用/输出参数、数组参数、泛型集合参数 | 14 | 能做 | 补参数形状 |
| 数据库、外部目标、打印机、自带事务、过时、内部 | 14 | 做不了 | SQL Server、打印、删除项目、比较项目合并等，按既有规则拒绝 |

估算：**能做** 约 400–500 组（主要靠返回链和静态调用），**要负责人决定** 约 280 组，**做不了** 约 230 组。全部做完后可调用约 3150–3250 组（78–81%）；负责人批准的规则全部开放时约 3450 组（86%）。

## 4. 顺序

1. 批量跑完 660 组（进行中），导入结果，重新生成覆盖报告。
2. 202 组专用工具和通用读取用工具的 Large 类核对，补实机记录。
3. 564 组“需要上下文”按类型补配方，分轮重跑；每轮只跑受影响的组（`EPLANMCP_BATCH_ONLY`）。
4. 202 组“夹具里没有对象”换副本重跑。
5. 第 3 节“能做”的部分：先补返回值和参数形状（约 80 组，改动小），再做静态调用和返回链。新开放的组同样进批量验证。
6. 第 3 节“要负责人决定”的部分，每类写一份 Proposed 说明，由负责人逐类决定。

每轮结束更新本表的数字和 [路线图](../roadmap.md) 的操作层一行。
