# M4b 第一批：柜体 3D 布置工具

- 状态：设计（2026-11-12）
- 触发：负责人要求为“自动喂丝机”画 3D 柜内布置并出布置图页（柜体 RIT.1055500，不做布线和钻孔）
- 依据：api-notes A136（Electric P8 上的 spike 实测）、`scratchpad` 调研报告中引用的 eplan.help “API Pro Panel” 一章
- 变更级别：L2（新增工具家族，沿用现有写入安全模型：预览、审批、备份、一步撤销）

## 1. 目标与范围

把原理图里已有的设备放进 3D 安装布置，生成可交付的 2D 布置图页。第一批只做：

| 做 | 不做（以后再说） |
|---|---|
| 安装空间、柜体（按部件） | 3D 布线、导线长度 |
| 安装板上的导轨、线槽（按部件、长度、位置、方向） | 钻孔视图、NC 数据 |
| 设备放到导轨、安装板或柜门上（按设备标识，部件取自原理图设备） | 母排、铜排 |
| 读取布置：空间、柜体、安装面尺寸、已放置对象、还没放的设备 | 碰撞的自动避让（只报告重叠） |
| 布置图页：安装板视图、门板视图（模型视图） | 3D 宏的创建和编辑 |

## 2. 工具

全部是 full 档工具；写入工具默认预览（`dry_run` 省略或 true），执行需要审批，执行前备份项目，整批一个撤销步骤（A136：一个事务回滚干净）。

### 2.1 `eplan_layout_get`（只读）
- 输入：`project`，可选 `space`。
- 输出：安装空间列表（名称、36452 的值）；每个柜体的部件、外形包围盒、安装板和门的安装面（中心、宽高、方向）；已放置的 3D 对象（类型、设备标识、部件、包围盒、父对象）；原理图里有部件但还没有 3D 表示的设备（标识、部件）。
- 坐标约定照 A136：X 宽、Y 深（前门在小 Y）、Z 高，单位 mm；安装面上的位置用面坐标（左下为原点，向右 x、向上 y），由工具换算。

### 2.2 `eplan_enclosure_place`（写）
- 输入：`project`、`space`（例如 `UC1`，不带 `+`）、`part`、可选 `variant`。
- 做法：没有该空间就 `InstallationSpace.Create(project, space)`；`Cabinet.Create(space, part, variant)`；`SetParent(space)`（A136：不这样做柜体是“未放置”）。
- 返回：柜体、安装板、门的标识和安装面尺寸，供下一步定位。
- 拒绝：部件不在部件库、空间里已有柜体（第一批一个空间一个柜体）。

### 2.3 `eplan_layout_place`（写，批量）
- 输入：`project`、`space`、`items`（1–100 项，按顺序执行，前面放的导轨可被后面的设备引用）：
  - `rail` / `duct`：`part`、`length_mm`、`on`（`panel`）、`x_mm`、`y_mm`、`orientation`（`horizontal`/`vertical`）、可选 `id`（供后面引用）。
  - `device`：`tag`（原理图设备标识）；可选 `part`（缺省取设备的第一个部件）；位置三选一：`rail`（前面某项的 `id` 或已有导轨）+ `offset_mm`，`panel` + `x_mm/y_mm`，`door` + `x_mm/y_mm`。
- 做法：导轨、线槽 `Create` 后找第一个能吸到安装面基准约束的源约束点 `SnapTo(面, 角度, x, y)`；设备 `Component.Create(project, 父, part, variant, -2, list)` → 吸附 → `Function3D.Name = tag`（A136）。
- 读回：每项的父对象、包围盒、设备名；检查读回名称等于请求、对象在安装面范围内；同一安装面上包围盒重叠报警告，不回滚（ADR-0046 的做法）。
- 拒绝：设备标识不存在、设备没有部件也没给 `part`、引用的导轨不存在、坐标超出安装面。

### 2.4 `eplan_modelview_create`（写）
- 输入：`project`、`space`、`page`（新页全名）、`view`（`panel` / `door` / `cabinet`）、`viewpoint`（默认 `front`）、`style`（默认隐藏线）、可选位置和大小。
- 做法：建 ModelView 页（A136：ModelView、PanelLayout 都可），再执行 `InsertModelViewAction`，`LAYOUTSPACE` 用 36452 的值；`view` 换算成 `ROOTELEMENTS`（安装板或门的 `FUNCTION3D_ID_RELATIVE`）。
- **已验证（A136，2026-11-12）：** `ActionManager` 调用返回 false，改用 `CommandLineInterpreter.Execute("InsertModelViewAction", ctx)`，在事务里可用。页由 `eplan_page_create` 新建（新增页类型 `ModelView`），本工具只往已有的 ModelView/PanelLayout 页上插视图。

## 3. 安全

- 只写当前打开的 scratch 项目（现有 Writable 检查）；scratch 外按现有审批模型。
- 不写系统主数据：柜体和器件宏从部件库读，3D 宏随部件复制进项目，和放置 2D 宏一样（普查事故后的主数据保护不涉及这些工具）。
- 每次执行一个事务；读回不符的硬性项（名称、父对象、部件）回滚，重叠只警告。

## 4. 测试

- Small：请求校验、坐标换算（面坐标 ↔ 世界坐标）、重叠判断、读回比较，用假适配器。
- Large（Electric P8，LargeWrite 副本）：柜体 RIT.1055500 → 导轨、线槽 → 两个设备上导轨 → 门上两个按钮 → 布置图页；断言读回和一步撤销。
- 验收：用这些工具画“自动喂丝机”的 3D 布置和两页布置图。

## 5. 交付顺序（每批一次门禁）

1. `eplan_layout_get` + 契约 + 坐标换算；
2. `eplan_enclosure_place`；
3. `eplan_layout_place`；
4. `eplan_modelview_create`（先测插件内调用 action）；
5. 画自动喂丝机。
