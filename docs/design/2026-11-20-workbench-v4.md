# Workbench 4.0：按 2026-11-20 设计稿逐页复刻

负责人 2026-11-20 提供新版设计稿（“EplanMcp Workbench 4.0 — 完整交互设计规范”，本机文件，不入库），要求一比一复刻。设计稿是单个 HTML 原型，带浅色、深色、高对比、中英、1360×812 与 1024×640 两种尺寸，以及连接、忙碌、空数据、出错等状态切换。本文记录逐页差距和实施顺序；视觉规则沿用 [ADR-0034](../adr/0034-workbench-visual-apple-principles.md)，新增的数据通道和人工操作见 [ADR-0065](../adr/0065-workbench-as-host-client.md)，检查更新见 [ADR-0066](../adr/0066-manual-update-check.md)。

## 1. 范围分三类

| 类 | 内容 | 前提 |
|---|---|---|
| A 纯界面 | 版式、控件、状态、弹层；只显示 Workbench 已有的数据（审批、审计、日志、配置、客户端、插件注册） | 无，直接做 |
| B 项目数据 | 结构树、页、宏、页内设备、设备清单、报表清单、网表、原理图示意、核查结果、EPLAN 实例与会话 | ADR-0065 接受 |
| C 人工操作 | 导出 PDF/DWG、报表生成与刷新、放置窗口宏、项目核查、保存、附着或打开项目、重启或停止 Host、检查更新 | ADR-0065、ADR-0066 接受 |

ADR-0065、ADR-0066 已于 2026-11-21 接受；B、C 实现之前按设计稿的“未连接”或空状态显示，按钮不可用并说明原因，不做假数据。

## 2. 逐页差距（A 类）

| 页 | 设计稿要点 | 现状 |
|---|---|---|
| 外壳 | 38 px 标题栏：品牌、`/`、当前页名；居中 350 px 搜索框；左栏开关、主题、语言、窗口按钮。26 px 状态栏：会话按钮（✓、EPLAN 版本与变体、项目）、客户端与 PID、审批模式、核查计数、审计序号、版本。60 px 活动栏三组 | 标题栏带环境标签；状态栏缺核查计数和审计序号 |
| 协作与审批 | 顶部“协作与审批 / AI 调用记录”切换和“待处理 / 已处理历史”分段；队列卡片（类别、时间、目标、摘要）；详情带客户端·请求号·工具的一行、标题、带行号的差异表、底部说明和按钮；历史是表格（时间、工具与对象、来源客户端、决定与执行结果、审计链、说明） | 队列与已处理同列；差异无行号；无历史表 |
| AI 调用记录 | 全部 / 写入 / 失败筛选、搜索、跟随最新；表格加右侧检查器（JSON 高亮） | 有表格，无检查器 |
| MCP 服务 | 连接方式两张卡；虚拟机地址、端口、宿主机 IPv4、测试连接、放行防火墙、停止服务、端点行；EPLAN 2024–2027 版本卡片与工具数；Host 路径；本机 Host 进程列表；服务活动日志 | 只有连接方式两卡和空的版本区 |
| AI 客户端 | 11 个客户端卡片可多选，显示配置文件路径和检测状态；预览 JSON、备份并写入；Claude Code 本地插件市场 | 有卡片和市场，选择与写入方式不同 |
| 环境检查 | 通过数标签、“全部通过 / 只看失败”切换、重新检查；插件变体管理卡（P8、Pro Panel 勾选，注册、卸载）；失败项置顶、红底、一键修复和手动步骤；通过项列表带分类标签 | 四个空计数卡和注册按钮 |
| 审计记录 | “最新记录 / 更早记录”标签与计数；常规、校验中、链完整、链断裂四种状态；表格（序号/时间、事件、工具与对象、结果、SHA-256、来源）；右侧检查器（前一哈希、本条哈希） | 五个下拉筛选和表格 |
| 运行日志 | 全部 / 警告 / 错误；导出诊断包、清空；“存储与保留设置”链接；单行日志（时间、级别、来源、内容） | 有表格和按钮，样式不同 |
| 设置 | 三节：安全与审批（普通写入审批开关、超时分段、登录自启、scratch 根目录与保存）；外观与语言（主题卡片、强调色、语言分段）；存储、更新与关于（关于卡、日志轮转单文件上限与份数、诊断包、四个目录） | 三节已有，缺 scratch 根目录、强调色单选、日志轮转、目录卡 |
| 弹层 | 会话弹窗、EPLAN 实例选择、普通确认框、破坏性输入确认、命令面板、忙碌细线与浮动卡、环境横幅、断开横幅、toast | 有命令面板、破坏性确认、toast |

日志轮转（单文件上限、保留份数）和 scratch 根目录可编辑要动 Host 的配置项，单独评审；在那之前只显示当前值。

## 3. 顺序

1. 外壳与状态栏；协作与审批、AI 调用记录。
2. 审计、日志、环境检查。
3. 设置三节、MCP 服务、AI 客户端。
4. 弹层与全局状态（会话弹窗、普通确认、忙碌、横幅）。
5. ADR-0065 接受后：项目页真实数据，然后人工操作；ADR-0066 接受后：检查更新。

每步截图与设计稿并排核对（浅色、深色各一张），过本地关卡后推送。
