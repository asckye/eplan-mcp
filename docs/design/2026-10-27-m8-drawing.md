## 1. 背景

负责人于 2026-10-27 决定现在启动 **M8 绘图**，与 M6 第 3 阶段并行。目标是代理按明确的工程输入画完整张原理图，工程师在 EPLAN 窗口观看；“自主设计电路”留到 M6 第 3–5 阶段之后。

负责人同日批准新增 **S43**，并提供真实 PLC 数字输入页作为 M8 验收页。该页及其绘图清单、截图和报告**仅限本地 scratch 使用，永不提交**（[CLAUDE.md 硬性规则 4](../../CLAUDE.md)）；仓库只记录元素种类，不记录其中的项目名、文字、标识或其他具体内容。自动化夹具由维护者从非客户材料独立构造，具有相同元素种类。

已有能力与缺口以 [api-notes](../eplan/api-notes.md) 为准，不以旧规格中的待测说明覆盖较新的实测记录：

| 已确认的事实 | 对 M8 的约束 |
|---|---|
| A13/A14：`Function.Create` 在 `SafetyPoint` 中失败；`UndoStep → Transaction` 可创建和撤销，提交前 finder 找不到新功能 | 库符号须验证完整的专用事务链，不能套现有宏事务，也不能用 finder 空结果判定创建失败 |
| A26 / [S20](../../spikes/S20-symbol-placement/README.md)：属性放置显示 `KF96`，缺 `-` 且压在插入点；`VisibleName` 仍为空 | S41 接续 M4c Q3，解决显示属性、位置和样式；按部件放置不能替代无部件符号 |
| A13/A19：对齐的线圈可生成连接；宏页生成 0→9 条，一步撤销；重复生成无增删时不留撤销步 | 已验证的是生成现有几何上的逻辑连接；任意折线、角连接、T-node、电位连接点仍须 S40 |
| A19：窗口宏插入、叠放/重名回滚已验证 | 继续复用 `eplan_macro_insert`；宏方案不能覆盖本期任意绘图需求 |
| A49 / [S38](../../spikes/S38-drawing-texts-frames/README.md)：已有自由文本可改、回滚、一步撤销；图框切换已接 `eplan_page_update.plot_frame` | 新建文本/图形、移动、编辑器显示与刷新尚未证明；标题栏页属性绑定仍有缺口 |
| A33：占位符不是自由文字；`GetAllCurrentValues` 需要写锁。A51：应用值集可整体替换多语言属性 | 不以占位符冒充文字；M8 不新增隐式值集应用或参数化电路语义 |
| A39/A36/A51：错误释放对象或反复获取/释放属性列表会导致原生崩溃；A41：撤销作用于当前项目 | 所有 spike 和产品适配器遵守同一生命周期与撤销检查 |

## 2. 目标与非目标

- **目标**：在示例材料派生的 scratch 项目中，按给定器件、连接表和坐标放无部件库符号；显示带前缀的设备标识及指定属性。
- **目标**：按显式路径布线，放角连接、T-node、电位连接点；区分可见自动连线与生成后的逻辑连接，并读回实际端点。
- **目标**：创建自由文本、直线、矩形；移动已放置的受支持对象；打开指定页供工程师查看，验证提交后的编辑器刷新。
- **目标**：S43 补齐中断点与 EPLAN 计算的交叉引用、虚线位置/结构盒、多线电缆定义及芯线/颜色、端子排单端子、PLC 盒与连接点的地址/符号地址/功能文本表，以及常开/常闭触点和连接点代号。
- **目标**：每次有效绘图写调用恰好一个撤销步骤；失败完整回滚，无变化不留空步；各能力有规格、Large 与 Agent 验收。
- **非目标**：自主选择电路拓扑、器件选型或工程规则；自动寻路/避障/自动布局；3D、跨页移动、符号库/图框主数据编辑、任意 action/代码执行。
- 首批限二维 `Circuit` 页；宏整组、嵌套组和额外表达的移动只有 S42 证明完整影响闭包后才开放，否则明确报告未支持，不宣称支持所有对象。

## 3. 方案概述与决议

先查目录、做 S40–S43 四个 spike，再发布小工具；Host 管契约、规划、策略与审计，Bridge 只做类型化适配。EPLAN 调用全部走既有串行队列、主线程调度、`LockingStep` 与模态/重入检查，不增加进程、JSON-RPC 方法或传输信封。

```mermaid
flowchart LR
    I[明确器件 / 连接表 / 坐标] --> P[查询符号与页对象 / dry-run]
    P --> W[既有策略 / 审批 / 指纹重核]
    W --> B[已验证的事务包装 / 实际值读回]
    B --> E[EPLAN 编辑器观看 / 刷新验证]
    B --> V[对象与连接验收 / 一步撤销]
    M[M6 后续工作流] -. 封闭步骤登记 .-> W
```

| 决议 | 选择及理由 | 否决的替代方案 |
|---|---|---|
| D01 L2 范围 | 图元、符号、连线、显示入口和既有工具兼容扩展均按 L2；设计先合并 | 不因“只是调用 API”跳过工具规格 |
| D02 布线 | 显式端点、路径和分支；由 S40 证明连接符号与 autoconnect 的组合 | 把图形直线当导线，或让代理自行推断接线 |
| D03 库符号 | 续 M4c Q3，扩展 `eplan_device_place`；保留原按部件调用 | 新建第二个设备放置工具、强制先找带部件宏 |
| D04 图框/属性 | 沿用 `eplan_page_update.plot_frame`、`eplan_page_text_replace`、已登记的属性工具 | 新建图框工具、修改图框内部文本、猜标题栏绑定 |
| D05 图形与移动 | 分离创建和绝对位置更新，保留各自幂等语义 | 把非幂等创建塞入幂等的 `eplan_page_update` |
| D06 观看 | 独立 `eplan_page_open`，只定位已打开项目中的页；S42 通过才标 Read | 把界面 action 加入 `eplan_action_run` 白名单；SEC-33 禁止该类条目 |
| D07 撤销 | 一个写调用一个原子范围；创建、显示属性和必要连接更新一起验收 | 多次提交伪装为一步，失败后自动 Ctrl+Z 补偿 |
| D08 与 M6 并行 | 先交付单步绘图，后登记可预测、可 guard 的计划步骤 | 等 M6 全部完成才画图，或把绘图成功称为电气设计正确 |
| D09 S43 与验收 | 负责人已批准扩围；按工程师先确认的绘图清单重绘，客户页只在本地 scratch 验收，仓库用独立虚构同类页 | 用静态文字模拟交叉引用/PLC 表，或将客户页及派生数据变成仓库夹具 |

不新增配置项、依赖、持久记录或审批例外，因此目前没有需要 L3 ADR 的决定。若 spike 迫使改变上述边界，只列负责人问题 O3，另提 `Proposed` ADR；本草稿不授权该变化。

### 4.3 坐标、布线与对象边界

以下是拟定产品合同；API 坐标换算、图上位置与栅格单位均为〔待验证〕，由 S40–S43 给出对应证据。

- 对外统一毫米，页左下角为原点、y 向上；只接受有限数，坐标非负且≤10,000 mm，再受实际页界限制。默认 `snap_to_grid=true`，明确按该页栅格计算并在 dry-run 显示请求值→实际值；关闭吸附时不偷偷纠偏。
- wire 路径 2–32 点，首批只支持显式正交段；端点用该页 locator+连接点索引，或经过验证的显式连接点坐标；T 分支必须显式声明。连接点朝向不兼容、斜段、歧义交叉、重复节点、非栅格接线均拒绝，不能自动选另一端点。
- 角连接/T-node/电位点如何编码、哪类能参与 autoconnect、对齐容差和遮挡规则全部由 S40 建立封闭支持表。代理给出路径，工具只执行该路径，不推断应接哪个器件。普通 `Line` 的用途在描述中明确为图形。
- 边界检查覆盖符号、显示属性、线/矩形和移动后全部跟随对象的外框，不只检查插入点。空页尺寸不可读时，只有 S42 证明的来源可用；否则拒绝新绘图并说明缺少页界，不沿用旧工具“仅检查非负”的宽松退路。
- locator 沿现有项目身份+类型/对象编号机制，附页/类型/原内容或几何摘要；不把裸句柄、`DatabaseIdentifier` 当稳定名称。执行前重新定位；会话句柄过期用 `HANDLE_EXPIRED`，状态变化用 `PLAN_STALE`。
- 首批移动只在同页；排除图框子对象、占位符引用、未证明的嵌套组/额外表达。属性文字可随其父符号移动，不能凭单独文字 locator 绕过父对象范围；重复 locator、父子同时指定均拒绝。
- 新图形/移动读取页布局和相关连接的完整影响范围；连接变化可能涉及整页，不能只观察新增对象。无法枚举真实影响或预测范围越界即拒绝，不通过截断缩小 guard。
- S43 每次仍以一个目标页的显式放置为任务，相关中断点引用、父端子排/PLC 归属及芯线闭包可跨页；所有派生影响必须有界、进入 readScope/modifyScope/审批，不能借“单页”漏掉其他页。跨页移动仍不支持。

### 4.4 事务、观看与结果

T0a 只读适配：`IPageDrawingReader` 返回页栅格、`Page.Size`、独立的 `PlotFrame.Size` 与受支持放置/属性文字的绝对外框；沿 A3 采用 1 API 单位 = 1 mm，吸附中点远离零。空页尺寸/外框不可读保留 null，图框尺寸不兜底页界；完整外框任一未知或越界即不能通过边界检查。locator 只含项目路径、页、类型/对象号和几何/内容 SHA-256，排除会话前缀、部件引用及图框子对象；属性文字附父 locator。尚不注册工具/操作，严格的发现输入、分页与覆盖报告留 T0b。

绘图写入复用 `WritePipeline` 的只读 plan、审批、指纹重核、execute 和 outcome 恢复。每次以单一目标页放置/更新≤50 项，派生影响依 4.3 完整核验，请求≤256 KiB；文字每项≤500 字符、显式语言，字高暂限 0.5–100 mm。规划/执行时限沿默认 60 s，超过 2 s 支持进度、每 5 s 心跳及安全点取消；不自动拆批以逃避一次审批或事务边界。

| 路径 | 拟定包装与提交条件 |
|---|---|
| 文字/图形/移动、连接符号 | 先测既有 `SafetyPoint → UndoStep → QuietModeStep`；事务内读回全部请求和受影响对象，一致才 `Commit → CloseUndo`。新用途仍须 spike，不能外推 A49 |
| 无部件功能 | A13 已否定 `SafetyPoint`；S41 验证显式锁定、`UndoStep → Transaction`、返回对象读回、Abort/提交/撤销。禁止同调用插宏；完整创建+属性显示不支持回滚时不发布此分支 |
| 布线/移动后的连接更新 | 默认要求可见几何和必要逻辑连接更新在同一原子调用内通过。`eplan_connection_generate` 仍保留独立用途；若创建与生成无法共用可回滚包装，不串两次提交冒充原子，工具保持不可用并交 O3 |
| 提交后的观看 | 在事务结束后观察打开的编辑器；若需刷新，仅使用 S42 证实无工程写入的 C13 路径。刷新失败不把已提交写入报成回滚，返回 `committed` 和警告；禁止自动重发绘图 |

`eplan_page_open` 只改变当前查看页/焦点：不保存项目、不改页属性/栅格/设置、不生成连接、不建 `SafetyPoint/UndoStep`、不调用打开或关闭项目的 action。按显式项目与页解析，忽略 UI 当前选择作为写目标；不用 `IGNOREWHENOPEN` 等自由参数。重复调用只确认/定位同页，不额外修改业务状态，因此拟为 Read；其界面副作用写入工具描述。

S42 必须证明打开/重绘前后业务快照不变、已有撤销历史不变，并单独报告 `User.*`/设置文件变化；不能只看对象计数或因文件属于 `User.*` 就忽略。发现工程数据或持久设置写入则不注册 Read 入口，不把有副作用的 action 暗中降级为只读。GUI action 不进入 `eplan_action_run`，产品优先用 C13 类型化调用。

输出均声明 `outputSchema`，回显实际 `project/page`；写工具带 `execution`、实际对象/坐标/变更、撤销说明和相关系统消息；dry-run 给完整变更范围、吸附/边界依据及预计连接变化，`execution=not_started`，不写项目、不审批。详情支持 concise/detailed，查询分页，保持 5k/20k 双份预算，全文日志不入库。

错误沿用 `INVALID_ARGUMENT`（集中列 violations）、`SYMBOL_NOT_FOUND`、`PAGE_NOT_FOUND`、`ALREADY_EXISTS`、`HANDLE_EXPIRED`、`PLAN_STALE`、`CAPABILITY_MISSING` 和既有策略/审批错误；未知范围或未验证符号返回缺能力，读回不符在事务内回滚。ADR-0010 四值不变：提交后取回结果、不重发；`OUTCOME_UNKNOWN/unknown` 暂停写入，交工程师核实。Read 不返回 execution。

### 4.5 与 M6 工作流计划组合

先交付单步工具；后来每个绘图写工具分别对应封闭 plan step（如 `device.place`、`connection.create`、`placement.create/update`），既有 `page.update`/`connection.generate` 按能力补齐。符号查询提供编译证据，打开页是独立观看操作，不作为生成成功的前置事实。

接入时复用既有步骤信封、局部 readScope/modifyScope、全项目名称筛查、柜边界、资源哈希、planHash、审批/初备份与逐步 guard；一个绘图步骤仍一个撤销步，整份计划沿原来的逐步执行/首错停止，不能宣称整计划一次撤销。计划内同样禁止 `Transaction` 与宏包装混用。

新增 op 先补预测器、真实读回和范围证据再登记，不引入新的计划落盘字段/格式。M6 的配置/规则提供输入约束，M8 不生成规则或自主推理电路；完整电气关系和工程验收仍留 M6 后续阶段。

## 5. 安全与数据完整性

- 新写工具暂定 Write，只有回滚、一步撤销和作用范围均通过才发布；scratch 自动允许，scratch 之外按现行策略逐次由工程师在独立窗口批准。不会因“工程师在看”跳过审批，也不把观看视作批准。
- 研发与 Large **只用 scratch 副本**，绝不试写真实项目；不扩大 scratch 根、不写系统符号库/部件库/宏/图框主数据。符号只接收已解析业务名称，不接任意文件路径。
- 负责人提供的客户验收页及其派生清单/截图/快照/报告只在本地 scratch 使用，绝不进入仓库、PR 或自动化测试资料；提交的夹具、示例与预期值均由非客户材料独立虚构，不能照抄后只换项目名。
- 审批清单列页、符号/方向、标识、属性、前后坐标、连接端点和全部连带变化；审批后布局/标识/库内容摘要变化即 `PLAN_STALE`。审计不可用零写入；审计含参数、实际差异、结果与关联 ID，默认日志不泄露工程内容。
- 失败显式回滚；无变化/失败不留空撤销步。撤销是工程师恢复手段，不是进程崩溃恢复保证；沿 ADR-0010 暂停与结果恢复，不新增自动补偿。
- A39：**从不释放 EPLAN 返回或项目持有的 `StorableObject`**，包括 Page、Function、SymbolReference、图元及符号库集合中的对象；新建项目对象交事务管理。C01 主动打开的库容器只按经 spike 验证的 `Close` 生命周期处理，不对借用对象套 `using`。
- 每对象每请求只取/释放一次属性列表；辅助 PropertyValue/ID/多语言值等按所有权释放。只读不调用 A33 的 `GetAllCurrentValues`，不为查询偷偷建立写事务。
- 自由文本、符号描述和属性值均为不可信数据，经 ResultShaper 清洗/截断；不拼接命令行，不把文本解释为动作、代码或审批。沿 TB1/TB3、T2/T3/T9/T10/T11/T15 与 SEC-01/05–09/13/14/18 防护，无新增信任边界。

| 方案 | 取舍 |

## 7. Spike 门槛

本设计不执行 spike。由维护者后续运行，结果补 api-notes，记录版本/变体、库与符号名/变体、输入、逐对象快照、耗时、系统消息、模态观察及文件差异；`failed/unknown/skipped` 不能当通过。S38 README 顶部的历史待测文字不覆盖 A49 和其结果段。

### 7.1 S40–S43 共用方法

1. 自动化探针从非客户示例/基本项目在关闭状态下制作完整 scratch 副本，保留 User.eod/eox；客户页仅用于获准的本地 scratch 验收，其原件只读、不提交。驱动和插件都验证规范化路径、目录边界、无链接/UNC、目标已打开。所有打开项目均为 scratch，写入/撤销只留目标副本且确认它为当前项目（A41/A46）；不代替工程师关闭其他项目。
2. 复用 S36/S38 的 action-return 后主线程调度与锁、超时/重入检查。先读基线，独立提交 sentinel，再测候选写入；各变体用独立副本，原材料前后哈希不变。只读发现不隐式创建测试样本。
3. 每条可写路径做 **SafetyPoint 显式回滚对照**、有效提交、提交后独立一次 `XEsUndoAction`、异常/取消回滚。A13 不兼容的创建必须记录 SafetyPoint 失败，再验证专用 Transaction.Abort，不能省略或声称 SafetyPoint 支持。
4. 一次撤销应只恢复本次全部修改，sentinel 仍在；受控第二次撤销才删除 sentinel。失败回滚后的下一次撤销必须直接删除 sentinel，证明无空步；首个不符即停，不盲目多撤销。撤销在锁/事务/action 完全结束后执行。
5. 业务快照与磁盘哈希分别比较，包含新增/删除文件；单列 User.*、设置与设计文件，不能称回滚等于字节恢复。持久性用另一轮提交后关闭重开验证，不依赖重开后的撤销历史。
6. A39/A36 的对象所有权规则贯穿全部模式；报告/截图/项目只留本地，不入库。未知结果不重试、不自动补偿；缺样本由维护者另在 scratch 准备，报告保留覆盖缺口。
