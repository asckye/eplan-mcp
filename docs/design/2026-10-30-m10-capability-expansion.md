## 1. 背景

2026-10-30 对 GitHub 上的 EPLAN 项目做了调研。同类项目中最完整的是 Canary-ECAD 的一组仓库（eplan-mcp、bochica、eplan-cloudflare-rags、eplan-scripting-skill、ecad-view）。项目负责人决定：**吸收其中全部好的功能，用本项目自己的代码实现**，并把约 1050 个界面 action 全部纳入。

这些仓库没有声明许可证，因此**不复制任何代码、数据集或整理出的清单**，只参考公开 README 描述的功能。本项目的安全模型（scratch、审批、事务、撤销、审计）保持不变。

## 2. 目标与非目标
- **目标**：下表 13 项全部落地；action 按 ADR-0030 分三级开放。
- **非目标**：不连接对方的在线服务；不分发 EPLAN 的安装文件或文档；不改变已发布工具的契约。

## 3. 功能清单

| # | 功能 | 现状 | 做法 | 级别 |
|---|---|---|---|---|
| 1 | 全部 action：B 级只读目录、C 级未验证执行、批量自动验证 | 只有 A 级白名单 | ADR-0030 | L3 |
| 2 | EPLAN 生命周期：启动、关闭、重启，替换插件后重连 | 只有脚本 | 新工具；关闭与重启只在没有未保存的非 scratch 项目时执行 | L2 |

| 5 | AAS 数字孪生导出与导入 | 无 | 先做 spike，结论进 api-notes | L2 |
| 6 | 从图片识别符号 | 无 | 用本机符号库导出的图片建本地索引；不用对方数据集或在线服务 | L2 |

## 4. 分批
1. **第 1 批**：B 级目录、批量验证工具、discovery Profile、生命周期工具、scratch 建项目、能力总览与多语言文档。
2. **第 2 批**：C 级执行（ADR-0030 接受后）、图片识别符号、本地文档检索与 action 核对、技能包、AAS。
3. **第 3 批**：浏览器查看器、私有扩展模块（ADR-0031 接受后）、Workbench 对照补齐。

v0.5.0（M6 第 3 阶段与 M8）先完成；M10 与 M9 并行或接续，按负责人安排。

## 5. 验收
- 每个新工具按工具规格模板写规格，Bridge 与写工具在 scratch 上实跑 Large；
- B 级目录在本机 EPLAN 2026 上列出全部 action，与安装文件条目数一致；
- 批量验证工具对全部 action 出具报告，报告与结论进 api-notes；
- C 级执行在 scratch 外一律拒绝，每次审批，审计带"未验证"标记。
